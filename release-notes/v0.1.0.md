# TvRestream v0.1.0 — MVP

The first version of TvRestream: an IPTV restream platform with built-in subscriber middleware. It covers stages
S0–S3 of the development plan (document 12): one server restreams channels from HTTP-TS / HLS / UDP sources to HLS,
with automatic failover to backup inputs, and subscribers watch them with a personal M3U link that is checked on
every playlist request.

## What is in it

**Channels**
- Channels with up to 8 inputs (HTTP-TS, HLS, UDP/RTP, SRT, RTMP, RTSP) and an HLS output; FFmpeg 7 runs on the
  agent, driven by tvr-core over gRPC (desired state + reconciliation).
- Failover to the next input when data stops, HLS discontinuity on a switch, manual switch and pin of an input.
- Input probe (ffprobe), basic TS analyzer (bitrate, PIDs, codecs, CC errors), channel log and event history.
- Categories, logos (upload PNG/SVG or an address), start / stop / restart.
- **M3U import**: a provider list by URL, file or text → preview → choose → import; existing channels are not
  created twice, repeated sources become backup inputs.

**Subscribers**
- Packages with ordered channels; subscribers with expiry date, device limit, IP allow list, personal token.
- Personal M3U playlist `/pl/{token}.m3u` with tvg-id / tvg-name / tvg-logo / group-title / tvg-chno.
- Protected playback through the nginx edge: `auth_request` to `/internal/auth` (token, status, expiry, package,
  IP), signed HLS segments (HMAC-SHA256, 60 s), concurrent device limit (`REJECT_NEW` / `KICK_OLDEST`).
- Automatic expiry at 00:00 Europe/Sofia, subscriber history (audit log).

**Admin panel** (BG / EN, light / dark)
- Dashboard with live counters and problem channels, channels list / detail / edit, servers with live metrics,
  packages, subscribers, import, admin users.
- Roles: Administrator, Operator, Support, Viewer — enforced by the API (document 02 §14).

**Operations**
- One-command dev environment (`scripts/dev-all.sh`), Docker Compose for PostgreSQL, Redis, nginx origin and edge.
- Ubuntu 24.04 `.deb` all-in-one package with `install.sh` and a GitHub release workflow; the package runs the edge
  for players on `:8081` (TVR-112) with the HLS origin on loopback.
- Install from source on the server: `sudo ./build.sh --static-ffmpeg` (builds, packages and installs).

## Known limitations

- The admin panel's channel preview (no subscriber token) works only from the networks in
  `/etc/tvrestreamer/nginx-preview-allow.conf` (local networks by default).
- One ingest server; cold failover only (hot standby < 3 s, multicast output, DVB, transcoding come in R1+).
- No session list / kick in the panel (TVR-066), no alerts (TVR-068), no 2FA, no Xtream Codes API yet.
- Ubuntu 24.04 ships FFmpeg 6.1: install with `--static-ffmpeg` for FFmpeg 7.

## Upgrade notes

First release — nothing to migrate. The database schema is created by Flyway (V1–V7).
